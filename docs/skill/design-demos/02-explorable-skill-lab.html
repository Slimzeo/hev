From raw trajectories to a target-specific intervention

成功轨迹暴露可行程序，失败轨迹暴露约束与死路。SkillLens 不把二者当作越多越好的语料， 而是固定 extractor、操纵经验池配比，再把 skill 放回 held-out 任务里测真实的性能变化。

关键问题不是「这份 Skill 写得是否像专家」，而是：在这个 domain 与 target 上， 它是否把原始经验压成了能改变行为的知识？

01 · Source evidence

曲线只回答「配比会改变 utility」，不回答「哪种配比永远最好」

作者从同一来源轨迹中采出五种经验池，成功比例依次为 100%、75%、50%、25% 与 0%。 每个池都经过同一 extraction pipeline，并在 SpreadsheetBench、SWE-bench Verified、ALFWorld 上由三个 targets 评估平均 Δ。

形状比单一均值更重要：SpreadsheetBench 需要足够多的正向操作程序，ALFWorld 的失败轨迹则更能暴露 invalid action 与 dead end。 全失败池仍然一致最差——「知道不能做什么」无法替代「知道怎样做成」。

论文支持：experience composition 是可独立操纵的 utility source，最优点随 domain 改变。
证据边界 / 论文不支持：用这三条曲线推出生产系统的全局最优采样比例。

02 · Controlled setup

为什么可信：固定其余环节，只移动经验池这一根杠杆

CONTROL 01

固定 extractor

五种 pool composition 都由 GPT-5.4-mini 抽取，避免把 extractor 能力变化误写成经验配比效应。

CONTROL 02

同源重采样

成功与失败轨迹来自同一 source pool；操纵的是 composition，不是换一批任务或换一种 harness。

CONTROL 03

held-out consumption

最终指标仍是 skill 对未见测试任务的 Δ，而不是 extractor 对文本清晰度或完整性的主观评分。
