# 一些设计方案的上下文

## DSH的skill发现机制

DSH 当前只有 Skill 发现和加载能力，没有官方的 dsh skill install 或 Skill 市场下载命令。dsh plugin add 安装的是 DSH 插件，不是 Skill。

DSH 默认按以下顺序发现：

1. <project>/.dsh/skills
2. <project>/.agents/skills
3. customSkillDirs
4. $DSH_HOME/skills
5. $DSH_AGENTS_HOME/skills
6. bundled skills

具体定义见 deepseek-harness/docs/subsystems/skills.md:64。

支持两种本地结构：

.dsh/skills/
└── paper-analysis/
    ├── SKILL.md
    └── scripts/

或者：

.dsh/skills/paper-analysis.md

名称必须为 kebab-case，且不会递归搜索任意深度的 SKILL.md。
