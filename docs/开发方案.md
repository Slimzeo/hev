4. 直接修改agent-preset，禁用skill-filesystem
相应的：hev plugin的实现也改为对于每个env新建一个agent-preset，并且需要知道skill的绝对路径来进行加载，需要在插件层补充SkillProvider对接@dsh-skill
官方预制的四种在deepseek-harness/apps/cli/config/agent-presets，个人自定义的放在.dsh/agent-presets 下
- 好处：
1. 后续也能同时在这里管理其他预设如MCP
2. 天然支持会话重启时加载特定的环境
3. 可以自然切回官方预设
- 坏处：
一个session只能在说话之前就确认选择一个env
```
  - id: skill-filesystem
    name: '@deepseek-ai/dsh-skill-filesystem'
    disabled: true
```
